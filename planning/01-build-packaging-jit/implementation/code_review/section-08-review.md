# Code Review: Section 08 - Device report

No high-confidence defects. Privacy, the schema validator, and the iOS 15 floor match the plan.

What matches the plan:

- Model: DeviceReport.make truncates generatedAt to whole seconds, sets schemaVersion 1, gates to [:], and notes to nil. encode/decode use sorted keys, pretty printing, withoutEscapingSlashes, and ISO-8601. There is no device name, UDID, or serial field, and DeviceSystem does not expose them. The evolution rule is a doc comment on DeviceReport. AppInfo.from turns a missing or empty Info.plist value into "unknown".
- Device info: LiveDeviceSystem.current() is main-actor, uses SIMULATOR_MODEL_IDENTIFIER on the simulator then hw.machine then "unknown", formats hw.cpufamily as 0x%08x (0 if the sysctl fails), formats the OS version as major.minor plus a non-zero patch, and reads kern.osversion. availableMemoryBytes() is os_proc_available_memory() at report time, including 0. SystemInfo.cpuFamily reuses sysctlUInt32 instead of a second helper. ChipNames includes iPhone14,4 → A15 and iPad14,5 / iPad14,6 → M2, and falls back to "unknown".
- JIT: usable is still encoded and ignored on decode. The encode(reason) → encodeIfPresent(reason) change omits a nil reason instead of writing null, which is what the fixture key-set contract requires. decodeIfPresent already accepts a missing reason.
- Export: copy and temporaryFile are @MainActor. The temp name is eikon-report-<UTC yyyy-MM-dd>-<model>-<method>.json with characters outside [A-Za-z0-9,._-] replaced by "_", and the write overwrites. ActivityView is a UIViewControllerRepresentable around UIActivityViewController with onComplete wired to completionWithItemsHandler. No ShareLink, NavigationStack, or Observation. Deployment target stays iOS 15.0; os_proc_available_memory and withoutEscapingSlashes are both older than that floor.
- Schema: draft 2020-12, additionalProperties false, required top-level fields omit notes, optionals (notes, jit.reason, probe.detail, GateResult.passed) allow null and are not required, schemaVersion is const 1, dates and filename parts use the specified patterns, gates values are GateResult, and enum-like fields are plain strings.
- Filer: stdlib only, repo root from the script path, known versions {1} before validation (bool and non-integers rejected), the listed keyword subset with any other keyword raising, problems collected as pointer strings and printed to stderr with exit 1 and no write, canonical SHA-256 filename, pretty sorted body plus newline, identical-bytes idempotence, different-bytes refusal, atomic replace, and --check printing the path without writing. Exit 2 is argparse's usage default.
- Fixture and tests: one neutral schema-version-1 fixture, nil optionals omitted, one gate, whole-second UTC timestamps, redacted evidence paths. Swift checks round-trip equality, exact key/string privacy against UIDevice.current.name and hostName for both a fake system and LiveDeviceSystem, and top-level plus jit key sets only. pytest runs the filer as a subprocess, derives the date from the fixture, and covers --check, idempotent filing, stdin, and the three rejections without pinning error text. No device-reports README.
