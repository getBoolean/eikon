# Stage 10: Publish the shell deb

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `eikon-source` serves the stage 1 package, and GitHub Pages returns the source page. Sileo can list Eikon. The package still does not run a guest.

**Architecture:** The apt repo is `getBoolean/eikon-source` only. Pages deploys `docs/`. The first choice is an ordinary `git push` from a machine where GitHub authentication works. The push failures in the handoff came from the remote Linux workspace, not from every machine. The Contents API is the fallback, and it sends binaries as raw bytes base64-encoded once. This stage starts only after `packages/com.getboolean.eikon_0.1.0_iphoneos-arm64.deb` exists from stage 1. The handoff's `1.0.0` file, size 388546, is not in this checkout and is not reused.

**Tech Stack:** `dpkg-scanpackages`, `bzip2`, `gzip`, GitHub Contents API, GitHub Pages.

## Global Constraints

- Package id `com.getboolean.eikon`. Architecture `iphoneos-arm64`. Version `0.1.0`.
- Do not put Theos sources, the IPA, `.theos`, Wine, FEX, or the Kirikiri engine on `eikon-source`.
- Do not describe the source as live until `https://getboolean.github.io/eikon-source/` returns the page.
- No program titles in the depiction.
- A 404 from the Contents API when creating `.github/workflows/pages.yml` means the token cannot write workflow files. Stop and report that. Do not retry with a different repo.

### Task 1: Rebuild the indexes from the new deb

**Files:**
- Create, in the `eikon-source` checkout: `docs/debs/com.getboolean.eikon_0.1.0_iphoneos-arm64.deb`
- Modify: `docs/Packages`, `docs/Packages.bz2`, `docs/Packages.gz`, `docs/Release`

**Interfaces:**
- Consumes: the stage 1 deb
- Produces: `Packages` whose `Size`, `MD5sum`, `SHA1`, and `SHA256` match that deb, and a `Release` whose hashes match the new `Packages`, `Packages.bz2`, and `Packages.gz`

- [ ] **Step 1: Copy the deb and scan**

Scan from inside `docs/`, so that `Filename` is `debs/...`, relative to the repository root that Sileo fetches from, not `docs/debs/...`:

```bash
mkdir -p docs/debs
cp /path/to/com.getboolean.eikon_0.1.0_iphoneos-arm64.deb docs/debs/
cp docs/Packages /tmp/Packages.previous
(cd docs && dpkg-scanpackages -m debs /dev/null > Packages)
```

Add `Depiction`, `Icon`, and `Sileodepiction` to the new `docs/Packages` with the `getboolean.github.io/eikon-source` URLs from `/tmp/Packages.previous`. Leave `Filename` as `debs/com.getboolean.eikon_0.1.0_iphoneos-arm64.deb`. `Version` comes from the deb and must read `0.1.0`. The description comes from the deb's control file.

Compress only after `Packages` is final, so the compressed copies match it:

```bash
bzip2 -c docs/Packages > docs/Packages.bz2
gzip -c -n docs/Packages > docs/Packages.gz
cmp <(bzip2 -dc docs/Packages.bz2) docs/Packages
cmp <(gzip -dc docs/Packages.gz) docs/Packages
```

- [ ] **Step 2: Rewrite `Release` hashes**

```bash
python - <<'PY'
import hashlib, pathlib
root = pathlib.Path("docs")
names = ["Packages", "Packages.bz2", "Packages.gz"]
for algo in ("md5", "sha1", "sha256"):
    print(algo.upper() if algo != "md5" else "MD5Sum")
    for name in names:
        data = (root / name).read_bytes()
        digest = getattr(hashlib, algo)(data).hexdigest()
        print(f" {digest} {len(data)} {name}")
PY
```

Replace the three hash blocks in `docs/Release` with that output. Expected: `Packages` is no longer 825 bytes and its SHA1 is no longer `5469eb948454805d60494a80d9d3e125d9141c73`.

- [ ] **Step 3: Commit in eikon-source**

```bash
git add docs/Packages docs/Packages.bz2 docs/Packages.gz docs/Release docs/debs
git commit -m "Publish the 0.1.0 shell package indexes."
```

### Task 3: Pages

**Files:**
- Create: `.github/workflows/pages.yml` in `eikon-source`

**Interfaces:**
- Consumes: task 2
- Produces: `https://getboolean.github.io/eikon-source/` returning the existing `docs/index.html` text, including the sentence that it is not a live source until this task has actually enabled Pages. After Pages returns 200, edit that sentence in `docs/index.html` so the page says the source lists the 0.1.0 shell and still does not run a guest.

- [ ] **Step 1: Add the workflow**

```yaml
name: pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: docs
      - id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Enable Pages for `getBoolean/eikon-source` on the GitHub Actions source**
